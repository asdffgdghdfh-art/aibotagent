接入只需三步

V1.1 · 初次连接向导
01

部署 Relay

在自己的 Linux 服务器上运行 Python/SQLite Relay，并通过 Nginx 设置 HTTPS。需要持续在线才能远程下发任务。

02

电脑安装 Bridge

在 Windows 或 Mac 启动 Bridge，授权指定的项目目录，获取一次性八位配对码。

03

手机配对并发任务

在 Relay 控制台批准配对，从手机选择自动路由。Codex 执行与日志由 Bridge 回传，重要操作遵循审批规则。
